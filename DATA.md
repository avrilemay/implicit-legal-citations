# Data availability

This repository ships the benchmark and the predictions needed to reproduce the paper's tables. The large artifacts (trained bi-encoder, chunked corpus, raw decisions) are archived on Zenodo ([doi:10.5281/zenodo.21206799](https://doi.org/10.5281/zenodo.21206799)) and can also be regenerated by the pipeline notebooks. This file documents all three.

## Shipped in `DATA/`

### `DATA/inputs/` — reference legal data

- `civil_code_articles.json` — Civil Code article number → article text.
- `civil_code_article_list.txt` — flat list of article identifiers.
- `equivalences_2016.csv` — old ↔ new article numbering (2016 contract-law reform).
- `equivalences_new_to_old.json` — reverse numbering map.
- `tribunal_insee_codes.xlsx` — tribunal → INSEE geography codes.

### `DATA/outputs/benchmark.csv` — the benchmark (1,015 pairs)

One row per annotated (chunk, article) pair.

| Column | Meaning |
|---|---|
| `decision_id` | Pseudonymised first-instance decision key (`docket__date`, e.g. `22/12811__2024-01-24`). |
| `chunk_id` | Index of the chunk within the decision. |
| `pred_art` | Candidate French Civil Code article number retrieved for the chunk. |
| `text` | Text of the decision chunk. |
| `article_text` | Text of the candidate Civil Code article. |
| `A1`, `A2`, `A3` | Binary label from each annotator: 1 = implicit citation, 0 = not. A1 and A2 label every pair; A3 only adjudicates the 339 pairs on which they disagree (blank elsewhere). |
| `eval_A1`, `eval_A2`, `eval_A3` | Fine-grained categorical label behind each binary decision (e.g. `Oui`; `Non, faits uniquement`). |
| `agreement` | 1 if A1 and A2 agree on the pair, 0 if they disagree. |
| `gold` | Gold label used for evaluation: the A1/A2 label when they agree, A3's label otherwise. |
| `fold` | Cross-validation fold id for the out-of-fold protocol. |

### `DATA/outputs/predictions/` — model predictions

All prediction arrays are aligned row-for-row to `benchmark.csv` (length 1,015).

- **`supervised_oof/`** — out-of-fold predictions for the 9 supervised systems (8 frozen encoders and the TF-IDF baseline): eight `.npy` score vectors (`JuriBERT`, `CamemBERT`, `CamemBERTav2`, `LLaMA`, `Lawma`, `SAUL`, `ST-MPNet`, `ST-MiniLM`) plus `TF-IDF.csv`, and `ensemble_oof.csv` (the combined ensemble probabilities and predictions).
- **`zeroshot_llms/`** — zero-shot predictions from 10 LLMs (`.xlsx`): `qwen2.5-7b`, `qwen2.5-32b`, `qwen3-32b`, `llama3.1-8b`, `llama3.1-70b`, `mistral-nemo-12b`, `gemma2-27b`, `aya-expanse-32b`, `command-r-35b`, `saul-7b`.
- **`fewshot/`** — `fewshot_results.csv`: BM25 retrieval-augmented few-shot MCC at k ∈ {0, 2, 4, 8} for the three evaluated models (`qwen2.5-32b`, `qwen2.5-7b`, `llama3.1-8b`) (Table 20, App. M). Per-row few-shot predictions are not shipped.
- **`baselines/`** — fine-tuned baselines: `bge-reranker-ft.npy` (BGE-reranker-v2-m3 fine-tuned cross-encoder, App. I, Table 15) and `xlm-r-xnli.npy` (XLM-R-large-XNLI further fine-tuned on the benchmark, out-of-fold predictions, App. J, Table 16).

### `DATA/outputs/bounding_risk.xlsx` — bounding-risk study

100 pairs rejected by the o3 adversarial filter, re-annotated by A1/A2/A3 (§3.6). **None** was confirmed as an implicit application, which bounds the rate of missed implicit citations among o3-rejected candidates below roughly 3% (95% CI). This is an upper bound on the selection bias, not evidence of its absence.

### `DATA/outputs/fp_error_annotation.csv` — false-positive error analysis (66 pairs)

Manual failure-mode annotation of the supervised ensemble's 66 false positives (App. U). One row per pair, keyed like `benchmark.csv`.

| Column | Meaning |
|---|---|
| `decision_id`, `chunk_id`, `pred_art` | Pair key, as in `benchmark.csv`. |
| `failure_mode` | `statutory_language_not_applied` (statutory language present in the chunk but not applied by the court), `wrong_rule` (right legal domain, wrong article or regime), or `other`. |

Table 30 is reproduced by `CODE/analysis/error_analysis.ipynb`.

### `docs/annotation_guide_bilingual.pdf`

The bilingual (French/English) guidelines given to the annotators.

## Archived on Zenodo and regenerated by the pipeline

These artifacts are too large for this repository. They are archived on Zenodo ([doi:10.5281/zenodo.21206799](https://doi.org/10.5281/zenodo.21206799)) and can also be regenerated by the pipeline notebooks, which read and write them under a local `artifacts/` folder referenced by relative path.

| Artifact | Zenodo archive | Regenerated by |
|---|---|---|
| Raw Judilibre decisions (~182k first-instance civil decisions, one JSON each) | `data/raw_decisions.tar.gz` | `CODE/pipeline/01_data_collection.ipynb` |
| Chunk splits and TF-IDF feature tables (parquet) | `data/training_chunks/` | `CODE/pipeline/03_dataset_creation.ipynb` |
| JuriBERT bi-encoder (with loading code) | `model/bi_encoder_juribert/`, `modeling.py`, `MODEL.md` | `CODE/pipeline/04_model_training.ipynb` |

The Zenodo archive also contains a copy of `benchmark.csv`, identical to the one shipped here.

Not shipped anywhere: the retrieval scores used by the unsupervised ranking of §5.3 (out-of-the-box cross-encoder and ensemble scores) and the per-row few-shot predictions. The ranking scores are regenerated by `CODE/analysis/unsupervised_ranking*.ipynb`.

Reproducing the paper's numbers does **not** require any of these: `CODE/reproduce/08_reproduce_results.ipynb` runs entirely on the shipped `DATA/outputs/`.
