# Data availability

This repository ships the benchmark and every artifact needed to reproduce the paper's tables. The large, raw, and re-derivable intermediates are **held back** and regenerated by the pipeline notebooks. This file documents both.

## Shipped in `DATA/`

### `DATA/inputs/` — reference legal data

- `civil_code_articles.json` — Civil Code article number → article text.
- `civil_code_article_list.txt` — flat list of article identifiers.
- `equivalences_2016.csv` — old ↔ new article numbering (2016 contract-law reform).
- `equivalences_new_to_old.json` — reverse numbering map.
- `tribunal_insee_codes.xlsx` — tribunal → INSEE geography codes.

### `DATA/outputs/benchmark.csv` — the benchmark (1,015 pairs)

One row per annotated (chunk, article) pair.

| Column | Meaning |
|---|---|
| `decision_id` | Pseudonymised first-instance decision key (`docket__date`, e.g. `22/12811__2024-01-24`). |
| `chunk_id` | Index of the chunk within the decision. |
| `pred_art` | Candidate French Civil Code article number retrieved for the chunk. |
| `text` | Text of the decision chunk. |
| `article_text` | Text of the candidate Civil Code article. |
| `A1`, `A2`, `A3` | Binary label from each annotator: 1 = implicit citation, 0 = not (blank where a pair was not assigned to that annotator). |
| `eval_A1`, `eval_A2`, `eval_A3` | Fine-grained categorical label behind each binary decision (e.g. `Oui`; `Non, faits uniquement`). |
| `agreement` | Inter-annotator agreement indicator for the pair. |
| `gold` | Adjudicated gold label used for evaluation. |
| `fold` | Cross-validation fold id for the out-of-fold protocol. |

### `DATA/outputs/predictions/` — every model prediction reported in the paper

All prediction arrays are aligned row-for-row to `benchmark.csv` (length 1,015).

- **`supervised_oof/`** — out-of-fold predictions for the 9 frozen-encoder supervised systems: eight `.npy` score vectors (`JuriBERT`, `CamemBERT`, `CamemBERTav2`, `LLaMA`, `Lawma`, `SAUL`, `ST-MPNet`, `ST-MiniLM`) plus `TF-IDF.csv`, and `ensemble_oof.csv` (the combined ensemble probabilities and predictions).
- **`zeroshot_llms/`** — zero-shot predictions from 10 LLMs (`.xlsx`): `qwen2.5-7b`, `qwen2.5-32b`, `qwen3-32b`, `llama3.1-8b`, `llama3.1-70b`, `mistral-nemo-12b`, `gemma2-27b`, `aya-expanse-32b`, `command-r-35b`, `saul-7b`.
- **`fewshot/`** — `fewshot_results.csv`: BM25 retrieval-augmented few-shot MCC at k ∈ {0, 2, 4, 8} for the three evaluated models (`qwen2.5-32b`, `qwen2.5-7b`, `llama3.1-8b`), matching the paper's few-shot table. (Per-row few-shot prediction dumps are held back — see below.)
- **`baselines/`** — fine-tuned baselines: `bge-reranker-ft.npy` (BGE-reranker-v2-m3 fine-tuned cross-encoder, App. T) and `xlm-r-xnli.npy` (XLM-R fine-tuned on XNLI entailment, App. S).

### `DATA/outputs/bounding_risk.xlsx` — bounding-risk study

The 100 pairs rejected by the o3 adversarial filter, re-annotated by A1/A2/A3, of which **0** were judged implicit — bounding the false-negative risk introduced by the filter.

### `DATA/outputs/fp_error_annotation.csv` — false-positive error analysis (25 pairs)

Manual failure-mode annotation of a random sample of 25 of the supervised ensemble's 66 false positives (quantitative error analysis appendix). One row per pair, keyed like `benchmark.csv`.

| Column | Meaning |
|---|---|
| `decision_id`, `chunk_id`, `pred_art` | Pair key, as in `benchmark.csv`. |
| `failure_mode` | `statutory_language_not_applied` (statutory language present in the chunk but not applied by the court), `wrong_rule` (right legal domain, wrong article or regime), or `other`. |

The sample draw and the appendix table are reproduced by `CODE/analysis/error_analysis.ipynb`.

### `docs/annotation_guide_bilingual.pdf`

The bilingual (French/English) guidelines given to the annotators.

## Held back and regenerated by the pipeline

These artifacts are not shipped because they are large and/or fully re-derivable. The pipeline notebooks read and write them under a local `artifacts/` folder referenced by relative path; each is produced by the step listed.

| Artifact | Approx. size | Regenerated by |
|---|---|---|
| Raw Judilibre corpus (182,155 first-instance civil decisions) | large | `CODE/pipeline/01_data_collection.ipynb` |
| Chunk and TF-IDF feature tables (parquet) | ~4.2 GB | `CODE/pipeline/03_dataset_creation.ipynb` |
| JuriBERT bi-encoder checkpoints | large | `CODE/pipeline/04_model_training.ipynb` |

Reproducing the paper's numbers does **not** require any of these: `CODE/reproduce/08_reproduce_results.ipynb` runs entirely on the shipped `DATA/outputs/`.
